# 후킹 공식 (첫 줄이 전부다. 스레드는 첫 2줄, 인스타는 첫 줄만 보인다)

1. **손해 회피**: "이거 모르고 ○○ 3년 썼다"
2. **반전**: "비싼 거 사지 마세요. ○○원짜리가 더 낫던데"  (비교 근거 있을 때만)
3. **구체 숫자**: "설거지 10분 → 3분 된 이유 하나"  (써봤음일 때만 실제 수치)
4. **질문**: "주방에서 제일 안 쓰는 물건 뭐예요?" → 답글에 대안 상품
5. **금지된 척**: "이건 알려주기 싫은데" 류 낚시는 근거 없으면 금지

## 구조 (스레드)
- 1번: 후킹 1줄 + 공감/문제 2~3줄 + 핵심 이득 1줄 (링크 없음, 400자 이내)
- 2번(답글): 상품 한 줄 + 링크 + 대가성 문구
## 구조 (인스타 캡션)
- 첫 줄 후킹 / 본문 4~6줄 / 마지막에 "링크는 프로필(또는 댓글)" + 대가성 문구 / 해시태그 5개 이내(첫 댓글로)
