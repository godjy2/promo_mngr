# 사람 말투 가이드 (AI 티 줄이기)

피할 것: "~에 대해 알아보겠습니다", "결론적으로", "다양한/효과적인/편리한" 남발, 3개씩 나열, 이모지 도배, 완벽한 문장 구조, "!"" 연속, "꿀팁 대방출" 류 정형 문구.
할 것: 
- 문장 길이 들쭉날쭉. 한 줄짜리 문장 섞기.
- 구체 디테일 1개 (장소·상황·시간대): "애 재우고 나서 설거지할 때"
- 약간의 불완전함: 군더더기 없는 단정 대신 "아마", "내 기준엔"
- 같은 어미 반복 금지, 매번 다른 도입
- 실제 경험이 아니면 경험담 형태 금지 (정보형으로)
