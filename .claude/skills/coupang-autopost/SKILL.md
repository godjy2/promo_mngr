# 쿠팡 파트너스 자동 포스팅 (딸깍)

입력 → 후킹 글 → 검수 → 예약 발행까지. 사람이 하는 일은 **링크 주기**와 **미리보기 승인 1번**뿐.

## 입력
- `/쿠팡 <쿠팡파트너스 단축링크(link.coupang.com/...)> [상품 메모] [써봤음]` — 링크는 여러 개 가능
- 링크 없이 `/쿠팡`만 치면 `products.json`의 대기 상품을 순서대로 사용
- `써봤음` 표시가 있는 상품만 **직접 사용 후기 톤**을 쓴다. 표시가 없으면 정보·비교·꿀팁 톤만 쓴다 (써보지 않은 경험을 지어내지 않는다).

## 절차
1. `config.json` 읽기 (페르소나, 말투, 채널, 발행 시각, 카테고리).
2. `list_accounts`로 활성 채널 확인. threads/instagram이 없으면 https://uplika.com/dashboard/connections 에서 연결하라고 안내하고, 연결된 채널만 진행.
3. 상품마다 `references/hooks.md`의 공식에서 후킹 3안을 쓰고 가장 강한 1안 선택. 문체는 `references/voice.md`.
4. 모든 글을 `python3 scripts/lint_post.py <json>`로 검수. 실패하면 고쳐서 재검수 (통과 전 발행 금지).
5. 미리보기를 **한 번에** 보여주고 "올릴까요?" 한 번만 묻는다. 승인되면:
   - Threads: `publish` + `threadItems` — 1번 글은 후킹+핵심(링크 없음), 2번 답글에 링크+필수 문구.
   - Instagram: 이미지 필수. 본인이 찍은 사진/상품 이미지가 없으면 인스타는 건너뛰고 이유를 알린다. AI 생성 이미지면 `isAiGenerated: true`.
   - `scheduledAt`은 config의 `postTimes`에 상품별로 분산 (같은 시각 연속 발행 금지, 하루 `maxPostsPerDay` 이하).
6. 발행 결과와 예약 시각을 표로 보고. `scripts/log_post.py`로 `posted.jsonl`에 기록(중복 상품 7일 내 재게시 방지).

## 절대 규칙 (법·플랫폼 준수)
- **대가성 문구 필수**: 모든 게시물 링크 근처에 "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다." 를 넣는다. 숨기거나 흐리게 쓰지 않는다 (표시광고법 위반 + 쿠팡 파트너스 약관). 린트가 강제한다.
- 가짜 후기·가짜 사용 경험·허위 가격/재고/효능 금지. 가격은 "링크에서 확인"으로 쓰고 숫자를 단정하지 않는다.
- 의료·건강기능식품 효능 단정, "최저가 보장", "무조건" 같은 과장 금지.
- 계정 여러 개 돌리기, 좋아요·팔로우·댓글 봇, 브라우저 자동조작으로 플랫폼 탐지 회피 금지. 공식 API(업리카)로 예약 발행만 한다.
- 글을 "AI가 쓴 티가 안 나게" 다듬는 것은 문체 문제로 허용하되, 사람이 쓴 것처럼 **사실을 꾸미지** 않는다.
