# 블로그 포스팅 모바일 (PWA)

`/블로그` 스킬 결과물을 폰에서 네이버 블로그 앱에 비공개 초안으로 올리는 정적 웹앱.

1. 소재·카테고리 입력 → Claude 앱용 요청문 복사
2. 완성된 본문 붙여넣기 → 제목/태그 10개/구조/금지표현 자동 점검
3. 제목·본문(서식 포함)·태그를 복사해 네이버 블로그 앱에 붙여넣고 **비공개** 저장

호스팅: 정적 파일이라 GitHub Pages(`/blog-mobile`)나 아무 정적 호스팅에 올리면 된다. HTTPS에서 열고 "홈 화면에 추가"하면 앱처럼 쓴다.
임시저장은 기기 localStorage에만 저장되며 서버로 전송하지 않는다.
